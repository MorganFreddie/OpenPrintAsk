## 手动拍摄步骤

1. 用 Chrome/Edge 打开上面的 URL，等回答加载完。
2. `Win + Shift + S` 或浏览器开发者工具的设备模拟，截 1440 宽的视口。
3. 保存为 PNG，单张控制在 500KB 以内（CSDN 上传限制）。
4. 如果只想截回答区，滚动到回答卡顶部，保留品牌栏和「实时」徽章更可信。
