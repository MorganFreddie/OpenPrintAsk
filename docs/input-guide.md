# 输入手册：把「打不好」说成可检索的问题

> 这份手册解决一件事：**同样的问题，怎么描述，才能让编译器识别出机型、材料、现象、已尝试和环境，从而搜到真正有用的证据。**
>
> 你不需要先学术语。你只需要按下面五个格子，把已经发生的事实填进去。

---

## 1. 为什么输入方式会决定命中率

系统不是把整句话直接丢给搜索引擎。它先做一次「问题编译」：

```text
你的原话
  → 槽位：机型 / 材料 / 现象 / 已尝试 / 环境 / 意图
  → 缺口：哪些信息缺了、哪些需要先排除
  → 查询任务书：每条 query 带站点、数量、时效、目的
  → 证据：官方 / 社区 / 通用，带 S 编号
  → 回答：结论 + 步骤 + 引用 + 分歧 + 追问
```

所以，**一句模糊的抱怨，会得到一组模糊的查询；一句带槽位的事实，会得到一组能验收的查询。**

最典型的差别：

| 说法 | 编译器读到 | 后果 |
|---|---|---|
| 「A1 打不好」 | 机型 A1；现象未知；材料未知 | 只能搜「A1 打印质量」，结果泛 |
| 「拓竹 A1 打 PLA，首层翘边，热床 60℃，工位空调直吹」 | A1 / PLA / 翘边 / 热床 60℃ / 空调直吹 | 能搜「A1 PLA 翘边 热床温度」「A1 首层 空调 挡风」，并触发环境缺口 |

## 2. 五个格子怎么填

### 2.1 机型：品牌 + 型号，有 AMS 就说

- 好：`拓竹 A1`、`拓竹 A1 mini`、`拓竹 P1S`、`创想三维 K1`、`Ender-3 V3`、`Saturn 4 Ultra`
- 不够：`A1`（可能是拓竹，也可能是别的品牌）、`我的机器`、`3D 打印机`
- 多色：加上 `AMS Lite` / `AMS` / `多色`，系统会单独生成换料、冲刷、废料塔的查询。

> 为什么：机型决定首层结构、热床类型、喷嘴结构、官方文档站点。只写「A1」时，系统只能按别名猜；写「拓竹 A1」才能稳定命中 `wiki.bambulab.com`。

### 2.2 材料：写全，混用要分开

- 好：`PLA`、`PETG`、`PLA + PETG 混用`、`光敏树脂`
- 加上品牌：`创想三维 PLA`、`爱丽兹 PETG`、`拓竹官方 PLA`
- 加上「是否官方材料」：`不是官方材料`、`第三方耗材`

> 为什么：PETG 要烘干、PLA 不一定；第三方耗材的直径公差和含水率会改变堵料/拉丝的判断。材料写全，系统才会问对缺口（例如 G4 只对吸湿材料追问烘干）。

### 2.3 现象：一句一个现象，说「什么时候、在哪、变成什么样」

- 好：`打印龟壳模型时喷头堵料`、`打小船时首层不沾，底部离开热床，还在继续打，成了炒面`、`换色时堵，单色不堵`
- 不够：`打不好`、`有问题`、`总是失败`

> 为什么：现象是查询的主词。`堵料` 会走堵头/挤出/热蠕变；`首层不沾` 会走清洁/热床/挡风；`翘边` 会走附着/环境。多个现象可以同时写，系统会保留多标签，但会去掉「翘边 + 首层脱落」这种重复。

### 2.4 已尝试：只写「你已经做过的」，不要把解决方法写进来

- 好：`已经停止打印、退料、关机`、`热床 60℃、加了胶水`、`回抽 0.8–1.2 都试过`
- 不够：`用打火机加热铁棒通喷嘴`（这是解决方法，不是已尝试）、`别人说换喷嘴`（这是听说的，不是你做过的）

> 为什么：系统会把「已尝试」当成排除项。如果你把解决方法写进「已尝试」，系统会以为你已经做过了，反而不再建议它。**这也是真实用户最常犯的一个错。**

### 2.5 环境：室温、气流、湿度、地区

- 好：`室内 30℃`、`工位空调直吹`、`浙江，梅雨季`、`卧室，关窗`
- 不够：`环境正常`、`家里`

> 为什么：PLA 翘边和 PETG 拉丝都对环境敏感；30℃ 会触发「热蠕变」分支，空调直吹会触发「挡风」，浙江/梅雨会触发「防潮/烘干」。环境缺失时，系统会追问，而不是硬编。

## 3. 三个可直接套用的模板

### 模板 A：单色堵料

```text
品牌：拓竹
机器：A1
材料：PLA、PETG
是否官方材料：否，使用创想三维、爱丽兹
常用耗材：PETG
现象：打印龟壳模型时会产生喷头堵料
已尝试：停止打印，退料，关机
环境：室内 30 度
解决方法：开机，撞针疏通喷头，加热喷头 230 度再进料
```

> 最后一行「解决方法」可以写，但系统会把它切掉，不当作「已尝试」。这样既保留你的经验，又不会污染缺口判断。

### 模板 B：多色堵料

```text
品牌：拓竹
机器：A1
多色实现形式：AMS Lite
材料：PLA、PETG
是否官方材料：否
现象：打印多色模型时会产生喷头堵料，单色不堵
已尝试：停止打印，退料，关机
环境：室内 28 度
解决方法：撞针疏通；拆喷嘴后用加热铁棒通喷嘴内部；加热喷头 230 度再进料
```

> 多色一定要写「单色是否也堵」。这句话会决定系统先查「喷嘴本身」还是「换料残留/冲刷不足」。

### 模板 C：首层不沾 / 炒面

```text
品牌：拓竹
机器：A1
材料：PLA、PETG
现象：打印小船模型时底部不在热床，打印仍在继续，产生炒面
已尝试：停止打印
环境：室内 28 度
解决方法：取床板，温水和洗洁精清洗正反面，沥干/擦干，热床烘干后再打
```

> 「还在继续打印」很关键：它说明这是**首层附着失效 + 没有及时停打**，不是单纯温度问题。系统会先让你洗板，再谈升温和挡风。

## 4. 常见错误与改写

| 错误写法 | 问题 | 改写 |
|---|---|---|
| `A1 堵了` | 缺材料、缺现象细节、缺已尝试 | `拓竹 A1，PETG，打印龟壳时喷头堵料，已停打退料关机，室温 30℃` |
| `A1 打多色堵` | 没写 AMS Lite、没写单色是否也堵 | `拓竹 A1 + AMS Lite，PLA/PETG 混用，换色时堵，单色不堵，室温 28℃` |
| `首层不沾，怎么办` | 没有机型/材料/平台/环境 | `拓竹 A1，PLA，小船首层不沾成炒面，已停打，室温 28℃，PEI 纹理板` |
| `热床 60 度还翘` | 只给一个数值，没给环境和平台 | `A1 mini，PLA，首层翘边，热床 60℃，工位空调直吹，PEI 板` |
| 把「通针/加热铁棒」写进已尝试 | 解决方法被当成已做 | 写到「解决方法」或最后补充，不要写进「已尝试」 |

## 5. 系统追问时怎么答

系统问的每一个问题，都对应一个它不能替你猜的槽位：

- 「你的机型是哪一台？（品牌 + 型号）」→ 补 `拓竹 A1`，不要只写 `A1`。
- 「多色是 AMS Lite 还是 AMS？」→ 这决定换料路径和冲刷量。
- 「喷嘴是可拆的吗？」→ 决定能不能建议通针/冷拉。
- 「PEI 板是纹理板还是光滑板？」→ 决定首层温度与清洁方式。
- 「空调是否直吹？」→ 决定要不要先挡风。

答完再点一次「开始诊断」，不要在原答案上反复加参数；一次只改一个变量，才能判断是哪一项起了作用。

## 6. 输入前检查清单

- [ ] 机型写了品牌 + 型号
- [ ] 材料写了种类，混用/第三方材料写清楚
- [ ] 现象写了「什么时候、在哪、变成什么样」
- [ ] 已尝试只写做过的，不写听说的、不写解决方法
- [ ] 环境写了室温/气流/湿度/地区
- [ ] 多色写了 AMS 类型，以及单色是否也堵
- [ ] 没有把 key、地址、个人信息写进问题

## 7. 这套手册的边界

- 词表和规则覆盖的是 FDM/树脂打印的常见问题，不是通用 NLU；换到牙科、法律等域要重写词表。
- 当前只有 7 个演示案例、20 条私域笔记，不能据此宣称「命中率 90%」。
- 公开证据不足时，系统会明确说「不足」，并把缺口变成追问；这不是失败，是设计。
- 真实用户的新说法，应该补进 `data/lexicon.json` 和 `data/cases.json`，再跑一次测试；这比改提示词更有效。
