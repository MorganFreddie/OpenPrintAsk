## 一、认可度：做“复现回执”，不做点赞榜、不做置顶

### 为什么不做点赞/置顶

点赞奖励的是“传播”，不是“有效”。旧帖高赞会长期压住新机型的新解法；帖子还会 404、被删、被厂商改版。置顶更是把一次判断固定下来，机型一换代就变成错误答案。

### 做什么

答案底部只问一句：**“这次照做，解决了吗？”** 三个按钮：解决了 / 部分解决 / 没解决。可选勾选“哪几步最有用”，可留一句备注（≤200 字，不公开展示）。

回执绑定的是 **机型 + 材料 + 现象 + 步骤 id + 日期**，不绑定帖子、不绑定用户身份。

### 怎么聚合

- 只看近 90 天；权重 `0.5 ** (天数 / 90)`；超过 180 天不参与排序。
- 少于 3 条不回显，避免“1 个人说好”被当成结论。
- 展示成一行事实，不做排名榜：
  `同机型同材料 8 人复现：洗板 6 成功 · 挡风 4 成功；最近 2026-10-28`
- 步骤旁只加一个小徽标，不改变步骤正文。

### 排序里的位置（关键）

硬顺序：**安全/官方基线 > 机型与固件匹配、来源新鲜度 > 复现回执**。

回执最多给候选加 15% 权重，不能把官方结论翻掉。这样即使某个“偏方”被刷了很多认可，也不会排到官方前面。

### 来源会消失、会过时，怎么办

- 每条公开证据存快照元数据：`url / title / fetched_at / content_hash / excerpt（≤120 字）`。
- 页面 404 时标“原页可能失效，摘要已留存”，引用不丢。
- 来源日期早于你的机型发布/固件版本时，标“可能不适用”并降权，但不删除。
- 过时是“显示出来并降权”，不是“悄悄消失”。

### 边界

这版是单实例、匿名回执：`client_id` 用本地随机 UUID，同一 `(client_id, run_id)` 只记一次，服务端限流。公网多人、账号、风控、审核不在 12 天范围内；征文里也只写“复现回执”，不写“万人社区”。

## 三、分工

### 我做

代码、测试、数据 schema、界面接入、文档初稿、live 检索、截图、仓库与提交、征文/README 更新。每天一个可运行增量 + 一条 changelog，晚上给你 10 分钟评审。

### 你做（按投入产出排序）

1. **5–10 条真实问题**（30–60 分钟）：你或群友实际遇到的，带机型、材料、现象、已尝试、环境，最好有照片和最后怎么解决的。这是测试集和案例库的原料。
2. **词表校对**（20 分钟）：你平时怎么说品牌、型号、地区、口语症状。可以直接改 `data/lexicon.json`，也可以批注让我改。
3. **20 条私域病例**（每条 3 分钟）：我給模板，你填“日期/机型/材料/现象/做了什么/结果”。这是“病例本”，不是知识库。
4. **live 密钥位置 + 授权**（5 分钟）：告诉我 key 在哪，或你在自己终端跑；我负责跑四案例、存 RequestId、截图。
5. **建远程空仓库**（5 分钟）：GitHub/GitCode 建空仓库，把 URL 给我；没有凭证就你自己 push，我保证本地提交干净。
6. **文案与可执行性评审**（每天 10 分钟）：哪句话像工具、哪步做不到、哪个按钮多余。
7. **参与阶梯**（选一层，我給任务卡 + review）：
   - 数据层：改 lexicon/病例，跑测试看界面变化。
   - 测试层：把真实句加进 `tests/test_planner.py`，看红→绿。
   - 界面层：改文案/CSS token，截图对比。
   - 逻辑层：在 planner 加一个小 extractor，我 review 后合入。
   - 发布层：commit message、changelog、远程 push。
8. **可选**：找 2–3 位真实用户试 3 条问题，记录“识别错在哪”。

## 五、验收与风险

### 验收命令

```powershell
python smoke.py
python -m unittest discover -s tests -v
python server.py --port 8766
```

### 验收标准

- 真实句能识别品牌+型号+地区气候+多症状；缺项显式提示，不猜。
- `/api/compile` 不触发搜索；UI 输入 300ms 内出识别结果。
- 回执聚合 <3 条不显示；181 天前的回执不进排序；官方结论不会被回执翻掉。
- live 四案例有真实 RequestId；截图不是 replay。
- `git status` 干净；`.env`、runs 不在提交里；远程链接可访问。

### 风险

- **key 没落盘**：目前 `.env` 和系统环境变量里都读不到 `WSA_SECRET_ID/KEY`，live 会被卡；replay 能开发但不能当参赛截图。
- **12 天**：先砍 P1/P2，绝不砍 P0-2/3/6；回执做不完就只做“本地病例复现”，不硬上社区。
- **表述要诚实**：单实例就写单实例；不把“回执”说成“社区共识”。
- **来源版权**：只存 ≤120 字摘要 + 链接，不整页搬运。
