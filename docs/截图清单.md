## 拍摄命令

```powershell
# 先起 live 服务
python server.py --mode live --port 8765

# 以 01-answer 为例；其他图改 URL 和输出文件名
& "C:\Program Files\Google\Chrome\Application\chrome.exe" `
  --headless=new --no-sandbox --disable-gpu --hide-scrollbars `
  --window-size=1440,2100 --virtual-time-budget=15000 `
  --screenshot="docs\screenshots\01-answer.png" `
  "http://127.0.0.1:8765/?case=a1-warping"
```

> Chrome 写完文件后可能因 crashpad 报错返回 exit 1；以文件是否生成、图像是否正常为准。
> 如果服务返回 401/403，先跑 `python live_check.py` 确认 key 和额度。
